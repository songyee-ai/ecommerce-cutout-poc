# 문제 정의서 — 이커머스 상품 이미지 누끼 자동화 PoC

작성일: 2026-09-22 · 작성자: songyee

> 이 문서는 **PoC를 만들기 전에** 작성했다. 성공 기준의 숫자와 정답은 모델을 한 번도 돌리기 전에
> 확정했으며, 결과를 본 뒤 기준을 고치지 않았다.

---

## 1. 도메인 설명

이커머스 상품 상세페이지와 썸네일 제작. 촬영한 상품 원본 사진에서 **배경을 제거해 투명 PNG를
만드는 작업**을 현장에서 "누끼"라고 부른다. 만들어진 누끼는 상세페이지 레이아웃, 배너, 썸네일,
광고 소재에 배경만 바꿔가며 재사용된다.

신상품 입고, 시즌 개편, 기획전 준비 때 이 작업이 한꺼번에 몰린다.

## 2. 현재의 문제

지금은 디자이너가 Photoshop에서 한 장씩 처리한다.

1. 파일을 연다
2. `피사체 선택` 또는 펜툴/퀵 선택으로 상품 영역을 지정한다
3. 경계를 다듬는다 (`선택 및 마스크`)
4. 배경을 지우고 PNG로 저장한다

**병목은 판단이 아니라 손이다.** 어디가 상품인지는 디자이너가 0.5초면 안다. 시간을 먹는 것은
경계를 따고 다듬고 저장하는 반복 동작이고, 이 시간은 상품 수에 정비례해서 늘어난다.

수업 분류상 **입력·전사** 유형에 가장 가깝다 — 한 형식(배경이 있는 사진)에서 다른 형식(투명 PNG)으로
옮기는 작업이고, 병목이 판단이 아니라 손이다. 다만 옮기는 대상이 텍스트가 아니라 픽셀 영역이라
네 유형 중 어디에도 정확히는 들어맞지 않는다.

### PoC 적용 가능성 사전 확인

수업이 제시한 "적용하지 않을 업무" 세 가지 필터를 먼저 통과시켰다.

| 필터 | 이 업무 | 판정 |
|---|---|---|
| 판정 기준이 사람마다 다른가? | "경계가 깔끔한가"로 합격선이 대체로 일치한다. 다만 그림자·받침 포함 여부는 미리 정해야 한다 (→ 4절) | 통과 |
| 틀렸을 때 되돌릴 수 없는가? | 결과가 나쁘면 디자이너가 다시 하면 된다. 고객·몸·법적 효력과 무관하다 | 통과 |
| 판정 기록이 없는가? | 기존에 만든 누끼 결과물이 남아 있어 정답 역할을 한다 | 통과 |
| 발생량이 충분한가? | 상품 수만큼 반복되며 입고·기획전 때 몰린다 | 통과 |

## 3. 개선 가설

분할(세그멘테이션) 모델로 상품 영역을 자동 추출하면 손 작업이 사라진다.

다만 **자동 누끼 도구는 이미 존재한다**(Photoshop 원클릭, remove.bg 등). 그래서 이 PoC의 가설은
"누끼를 자동화하면 빨라진다"가 아니라 아래 두 가지다.

> **가설 1 (배치)** — 폴더 단위로 한 번에 처리하면, 장당 원클릭을 반복하는 현행보다 전체 시간이
> 줄어든다.
>
> **가설 2 (신뢰도)** — 모델이 내놓는 신뢰도 점수에 임계값을 걸면, **손봐야 할 장을 미리 골라낼 수
> 있다.** 그러면 디자이너는 결과 전체를 눈으로 검사하지 않고 표시된 장만 확인하면 된다.

가설 2가 이 PoC의 어려운 부분이다. 가설 1만 있으면 "빠른데 쓸 수 없는 결과"가 통과해 버린다.

## 4. 정답 판정 규칙 (모델을 돌리기 전에 확정)

채점이 성립하려면 "합격"이 무엇인지 먼저 정의되어 있어야 한다. 아래 세 규칙을 고정한다.

- **R1. 그림자는 상품에 포함하지 않는다.** 배경과 함께 제거한다. (상세페이지에서 그림자는 보통
  배경 교체 후 다시 합성한다)
- **R2. 상품은 판매 대상 물체만이다.** 받침대, 화병, 사람 손, 휴대폰, 선반은 배경이다.
  (`e07`의 나무 받침, `h05`의 화병·손·폰이 여기 해당한다)
- **R3. 같은 상품이 여러 개면 전부 포함한다.** (`e02`의 스니커즈 2짝, `h01`의 머그 2개,
  `h05`의 가방 2개는 모두 상품이다)

**합격 판정:** 결과 PNG를 열었을 때 **디자이너가 추가 손질 없이 상세페이지에 바로 올릴 수 있으면
합격**이다. 경계에 배경색 띠가 남았거나, 상품 일부가 잘려나갔거나, 배경 물체가 함께 남았으면 불합격.

## 5. 대상 사용자

- **1순위: 이커머스 상품 이미지를 만드는 디자이너.** 반복 누끼에서 손이 풀려나고, 어려운 장에만
  집중할 수 있다.
- **2순위: 디자이너 없이 직접 상품을 올리는 소규모 셀러.** Photoshop 숙련도가 없어도 결과를 얻는다.

## 6. 성공 기준 (정량)

> **A. 품질** — 샘플 12장 중 **9장 이상**이 R1~R3 기준으로 합격한다.
> **B. 시간** — 12장 전체 처리 시간이 현행 수작업의 **1/3 이하**다.
> **C. 신뢰도** — 불합격한 장을 도구가 **미리 표시**한다. 즉 신뢰도 점수에 임계값을 걸었을 때
> 합격/불합격이 갈리는 구간이 존재한다.

### 숫자의 근거

수업 지침대로 근거는 **지금 사람이 하는 수준**에서 가져왔다. 현행 수작업은 품질이 사실상 100%이므로
품질로는 기준을 세울 수 없다. 그래서 **B(시간)에서 출발해 A를 역산**했다.

현행 12장 수작업 시간을 `N`이라 하자. 자동 처리 후 불합격 장만 손보면 걸리는 시간은 대략
`(도구 실행 시간) + (불합격 장 수 / 12) × N` 이다. 도구 실행 시간이 N에 비해 작다고 보면,
전체가 `N/3` 이하가 되려면 **불합격이 4장 미만**이어야 한다. 따라서 **합격 9장 이상**이다.

`N`은 추정하지 않고 실제로 잰다 (→ `docs/03_verification.md`). 12장 전부가 아니라 대표 5장을
재고 환산하며, 그 사실을 결과에 명시한다.

### 기준을 만족해도 도입하지 못하는 조건

성공 기준과 성질이 달라 점수와 섞지 않고 따로 둔다.

- **상품 사진을 외부로 보낼 수 없다.** 미공개 신상품·거래처 제공 이미지가 포함된다.
  → 외부 API 후보(remove.bg 등)는 성능과 무관하게 제외한다.
- **라이선스가 상업적 사용을 허용해야 한다.** 사내 업무 사용도 상업 사용으로 보는 조건이 있다.
  → 후보를 재기 전에 확인해 거른다.

## 7. 이 PoC에서 하지 않는 것

PoC는 판단이 서는 것이 목적이므로 범위를 좁혔다. 아래는 의도적으로 제외했고, 필요성은
`docs/04_limits_next.md`에 남긴다.

- 그림자 재합성, 규격 캔버스 배치, 썸네일 리사이즈 등 누끼 이후 공정
- 텍스트로 상품을 지목하는 방식(GroundingDINO 등) — 모델을 하나 더 얹어야 해 PoC 범위를 넘는다
- 파인튜닝 — 학습 데이터를 만드는 비용이 PoC 단계의 판단에 필요하지 않다
- 웹앱·배포 — 화면 완성도는 PoC의 목적이 아니다
